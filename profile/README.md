## 📌 About the project

Este ecosistema reúne distintos servicios independientes diseñados para gestionar procesos y funcionalidades de un sistema médico.

El proyecto utiliza una arquitectura de microservicios, permitiendo separar responsabilidades, facilitar el mantenimiento y mejorar la organización del backend.

## 🏗️ Architecture

La solución está organizada en diferentes componentes:

| Componente | Responsabilidad |
|---|---|
| API Gateway | Punto de entrada a los servicios |
| Eureka Server | Registro y descubrimiento de servicios |
| Microservices | Gestión de los distintos módulos médicos |
| Docker | Herramientas de contenerización |

## 🧩 Microservices

El ecosistema contempla módulos para:

- 👤 Gestión de pacientes
- 🩺 Historial médico
- 📅 Gestión de citas médicas
- 🏥 Hospitalización
- 🛏️ Gestión de habitaciones
- 👨‍⚕️ Gestión de personal médico
- 💊 Recetas médicas
- 🧪 Exámenes
- 💳 Facturación
- 🛡️ Previsión

Los repositorios y su documentación se encuentran disponibles en la pestaña **Repositories** de esta organización, según los permisos de acceso correspondientes.

## ⚙️ Technologies

- Java
- Spring Boot
- REST APIs
- Netflix Eureka
- API Gateway
- Docker

## 🎯 Project objectives

- Implementar una arquitectura basada en microservicios.
- Separar las responsabilidades de cada módulo.
- Facilitar la comunicación entre servicios.
- Centralizar el acceso mediante API Gateway.
- Gestionar el descubrimiento de servicios mediante Eureka.
- Mantener una estructura modular y escalable.
